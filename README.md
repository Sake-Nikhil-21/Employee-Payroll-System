# Employee Payroll System

## Abstract

Employee Payroll System is a C++ based payroll management project with a browser-based interface. It helps manage employee records, attendance, payroll calculations and payslips.

## Features

- Employee Management
- Employee Login
- Staff and Manager Roles
- Attendance Management
- Payroll Calculation
- HRA, DA and Bonus Calculation
- EPF and Tax Deduction
- Attendance Deduction
- Payslip Generation
- Browser-based Dashboard
- Local Storage for Data

## Technologies Used

- C++
- HTML
- CSS
- JavaScript
- LocalStorage

## System Workflow

Employee Profile → Attendance → Payroll → Payslip

## How to Run

1. Compile and run the C++ program using Dev-C++ or a compatible C++ compiler.
2. The program generates `employee_payroll.html`.
3. Open the generated HTML file in a web browser.
4. Login using the provided credentials.
5. Manage employees, attendance, payroll and payslips.

## Project Structure

The project combines a C++ launcher with a browser-based payroll interface.

## Conclusion

The Employee Payroll System provides a structured way to manage employee information, attendance, salary calculations and payslips through a simple web-based interface.
