# Project Details

## Project Name

Employee Payroll System

## Project Type

C++ Based Payroll Management System

## Objective

The main objective of this project is to provide a simple system for managing employee information, attendance and payroll calculations.

## Main Modules

### 1. Login Module

Provides administrator login for accessing the payroll dashboard.

### 2. Employee Management

Allows employee details such as name, role and basic salary to be entered.

### 3. Attendance Module

Allows working days and present days to be entered and calculates absent days.

### 4. Payroll Module

Calculates salary components including:

- Basic Salary
- HRA
- DA
- Bonus
- Gross Salary
- EPF
- Professional Tax
- Net Salary

### 5. Payslip Module

Displays payroll information and provides an option to print the payslip.

## Methodology

Input → Validate → Calculate → Store → Display

## Technologies

- C++
- HTML
- CSS
- JavaScript

## Working

The C++ program generates an HTML file containing the payroll interface. The generated file can be opened in a web browser.

## Expected Output

The system provides:

- Login Page
- Dashboard
- Employee Table
- Attendance Section
- Payroll Calculation
- Payslip Printing
